# Lab Manager

`Lab Manager` - лабораторный менеджер, это программа для учёта материального обеспечения, а также анализа реактивного обеспечения.


## Структура хранения информации
Основой являются `#tag`s, к ним привязывается название `sql` таблицы, а так же и их структура,
иными словами все операции производятся над тегами.

## Примеры

Создадим тег `#glu` - эта таблица хранит в себе все реактивы, что используют для анализа глюкозы.
И другие теги можно использовать так же.

К тегам можно назначить шаблон заполнения, что заполняет поля автоматически, те поля, что не будут меняться (предположительно).
